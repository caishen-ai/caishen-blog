## 一、为什么你的AI总是不给力

先看一组对比。

**普通提示词**：「帮我写一篇关于数字产品的推广文章」

AI输出：一段泛泛而谈的介绍，毫无转化力。

**高手提示词**：

```
你是一位有5年经验的内容营销专家。帮我写一篇推广文章，目标读者是想做数字产品的个人创业者。
文章结构：
1. 痛点开头（选题难、做出来没人买）

**差距在哪？** 好提示词给了AI三个关键信息：角色（你是谁）、任务（做什么）、约束（怎么做）。

## 二、万能Prompt框架：一个公式覆盖所有场景

经过反复验证，我总结出一条万能公式：

> **角色设定 + 核心任务 + 约束条件 + 输出格式**

这个四要素框架，适用于99%的使用场景。拆开来看：

### 1. 角色设定
让AI切入特定视角，大幅提升输出质量。

- 不要：「帮我分析市场」
- 要：「你是一位在电商行业做了8年的运营总监，帮我分析一下……」

角色越具体，输出越专业。

### 2. 核心任务
用一句话说清楚你要什么。关键：**动词要精准**。

- ❌ 「随便写点什么」
- ✅ 「列举10个」「对比分析」「按以下结构撰写」

### 3. 约束条件
这是拉开水平差距的部分。好提示词都有限定：

- 字数限制、语气风格、目标读者
- 必须包含的元素、禁止出现的内容
- 参考案例或对标风格

### 4. 输出格式
明确你想要的产出形式：

- 「用表格呈现对比数据」
- 「每个要点不超过50字」
- 「输出JSON格式方便后续处理」

### 实战对比

拿「写产品文案」这个任务，看三档提示词的区别：

| 等级 | 提示词 | 输出质量 |

| 进阶 | 你是一个运营，帮我写一款AI选品工具的推广文案，800字 | 6/10 |
| 高手 | 你是一位出过3本营销类畅销书的增长专家。目标读者是年入30-50万的自由职业者，写一款AI选品工具的推广文案。开头用他们最痛的话题（选错方向浪费半年时间），中间给出3步解决方案，结尾引导免费领取。800字，语气像你私下跟朋友安利一个好东西，不要推销腔。 | 9/10 |

## 三、内容创作场景：25个拿来就用的提示词

### 公众号长文
```
你是一位10万粉公众号主理人。选题：{话题}。目标读者：{读者画像}。
写一篇2500字的公众号文章，结构如下：
1. 用真实数据或故事开头，制造好奇心（200字）
2. 拆解3个关键要点，每点含案例（各500字）
3. 总结+可立即执行的行动清单（200字）
语气：平实有料，多用短句，每段不超过3行。
```
### 小红书爆款笔记
```
你是小红书某领域的10万粉博主。写一篇关于{话题}的小红书笔记。
要求：
- 标题含数字和情绪词（如「被问了100遍」「后悔没早知道」）
- 正文分点+emoji，每点1-2句
- 结尾引导评论互动
- 正文不超过400字
- 5-8个相关话题标签
```

### 知乎高赞回答
```
你是{领域}资深从业者。知乎有个问题：「{问题}」
写一个专业但有温度的回答（1500字）：
1. 先判断提问者真正关心什么（共情开头）
2. 给出具体可执行的方法（不要空谈理论）
3. 附上真实案例或数据佐证
4. 结尾引导关注和私信交流
```

### 短视频脚本
```
你是短视频策划。写一个60秒的抖音/小红书短视频脚本，主题：{主题}
脚本结构：
- 前3秒：制造悬念或抛出反常识观点（钩子话术）
- 4-45秒：核心内容，分3个要点
- 45-55秒：总结+金句
- 55-60秒：引导关注+留言
每句话可朗读时间不超过8秒。
标注画面建议和运镜方式。
```

## 四、营销推广场景：让AI写出能转化的文案

### 产品着陆页
```
你是转化率优化专家。为一款{产品}写着陆页文案。
页面结构：
- HERO板块：一针见血的标题+副标题+主CTA按钮
- 痛点区：3个用户最痛苦的场景描述
- 方案区：产品如何解决每个痛点
- 信任区：真实数据/案例/好评
- 行动区：限时优惠+二次CTA
每个板块配套设计建议（配图/颜色/排版方向）。
```

### 朋友圈卖货文案
```
你是一个很会发朋友圈卖货的微商老手。产品：{产品信息}
写5条朋友圈文案，覆盖不同角度：
1. 客户好评晒单（含聊天截图描述）
2. 使用场景/体验分享（故事化）
3. 限时活动/倒计时（紧迫感）
4. 产品对比/为什么选我们
5. 日常晒单（伪自然，不要太推销感）
每条150字以内，配emoji，语气像朋友的日常分享。
```

### 商业模式推演
```
你是麦肯锡战略顾问。我有个商业想法：{商业想法简述}

1. 竞品价格带分布（找3-5个竞品对比）

3. 3套定价方案（引流款/利润款/旗舰款）

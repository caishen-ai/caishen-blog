## 🛠 How It Works

The humanizer applies multiple layers of transformation:

1. **Transition replacement** — Robotic connectors ("Furthermore", "Moreover") → Natural flow ("Plus", "Also")
2. **AI pattern removal** — Eliminates telltale AI phrases ("In conclusion", "It is worth noting")
3. **Formality adjustment** — "Utilize" → "use", "Commence" → "start"
4. **Sentence variety** — Breaks repetitive structures, varies sentence starters
5. **Style overlay** — Applies tone-specific rules (casual, professional, creative)

All processing happens in your browser. Zero server calls.

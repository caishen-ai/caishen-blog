## 为什么80%的数字产品死于选品阶段

去年，一个朋友花3个月做了套「小红书运营SOP模板」，上线后卖了17份——还不够他请我喝咖啡的钱。

他不是不努力。他做了竞品调研、写了50页的内容、设计了精美的PDF。但他漏了一件事：**小红书运营SOP的市场需求远比他想象的小**，而且免费替代品一大堆。

这不是个例。我做数字产品两年，见过至少50个类似的案例：

- 花2个月做「AI绘画提示词库」→ 发现Midjourney官方已经内置了
- 花1个月做「Notion模板大礼包」→ 市场上有3000+竞品，免费的一大把
- 花3周做「面试宝典PDF」→ 知乎上免费回答比他的付费内容还详细

三个最常见的选品错误：

1. **「我觉得这个有用」≠ 市场需要**。你做的产品是给你自己用的吗？
2. **有需求 ≠ 有人愿意付钱**。免费信息充足时，付费意愿为零。
3. **做竞品分析时只看成功案例**。那些做出来卖不动的，你看不到——但它们才是大多数。

> 延伸阅读：[一人公司AI全栈工具指南](/one-person-company-ai-stack/) — 做数字产品前，先把你的单人产能拉到极限。

一个好选品的3个特征：
- ✅ 需求明确且紧急（用户主动搜索解决方案）
- ✅ 付费替代品稀缺（不是免费信息就能解决）
- ✅ 你有独特视角或效率优势（AI可以帮你放大这个优势）

## 12维度需求验证框架

选出方向后，别急着做。用这12个维度验证一下，能帮你筛掉80%的伪需求：

### 需求维度（1-4）

| # | 验证点 | 怎么验证 | 红线 |
|---|--------|---------|------|
| 1 | **搜索量** | 百度指数/微信指数/谷歌关键词规划师查月搜索量 | 核心词月搜索<1000 → ❌ |
| 2 | **付费信号** | 淘宝/拼多多搜同类产品，看月销量 | 同类产品月销<10单 → ❌ |
| 3 | **论坛热度** | 知乎/小红书/豆瓣相关帖子数+评论情绪 | 连续3个月无新讨论 → ⚠️ |
| 4 | **痛点强度** | 看用户用了什么词：「急」「求」「跪求」「救命」「崩溃」 | 平淡讨论 → ⚠️ |

### 供给侧维度（5-8）

| # | 验证点 | 怎么验证 | 红线 |
|---|--------|---------|------|
| 5 | **竞品数量** | 淘宝/小红书/知识星球搜，统计前3页 | 竞品>50且同质化严重 → ⚠️ |
| 6 | **竞品质量** | 买2-3个竞品实际体验，看是否够好 | 竞品质量已经很高 → 你有差异化吗？ |
| 7 | **免费替代** | 搜"免费+关键词"，看有多少可用的免费内容 | 免费资源质量高 → 付费意愿低 |
| 8 | **价格天花板** | 最高价产品卖多少钱？ | 天花板<¥50 → 很难做大 |

### 可执行维度（9-12）

| # | 验证点 | 怎么验证 | 红线 |
|---|--------|---------|------|
| 9 | **你能做吗** | 估算你需要的时间+技能+资源 | 超出能力圈 → 先学会再说 |
| 10 | **AI能加速吗** | 用AI生成MVP版本试一下 | AI帮不了 → 效率优势消失 |
| 11 | **推广渠道** | 你有触达目标人群的渠道吗？ | 完全无渠道 → 冷启动难 |
| 12 | **迭代空间** | 产品能持续升级吗？ | 一次性产品 → 长期价值低 |

评分：每项1分（满分12分），低于7分不建议做，低于5分直接放弃。

## 3步竞品分析：找到你的差异化切口

### 第1步：找到真正的竞品

不是你以为的那些。

- 在淘宝搜核心词 + "教程"/"模板"/"资料"
- 在知识星球搜核心词
- 在小红书搜核心词 + "推荐"/"求"
- 在知乎搜核心词，看高赞回答是否在卖东西

**关键**：只看付费产品，免费的竞争对手不是竞品——用户对比的是「他能免费获得的」vs「你让他付钱的」。

### 第2步：买2-3个竞品深度体验

花点小钱，买个明白。重点看：

- 封面和标题怎么写的（转化第一关）
- 目录结构（内容深度判断）
- 实际内容质量（你能做得更好吗？）
- 用户评价（好评说什么、差评吐槽什么）
- 配套服务（有没有社群、更新、售后）

### 第3步：找到你的差异化

差异化不是「我的更好」，而是「我的不一样」：

| 差异化维度 | 例子 |
|-----------|------|
| 人群细分 | 通用「项目管理模板」→「电商运营专属项目管理模板」 |
| 格式创新 | PDF电子书 → Notion可交互版 + AI辅助工具 |
| 深度升级 | 基础教程 → 含真实案例的深度实操手册 |
| AI加持 | 静态模板 → 内置AI分析功能的动态模板 |
| 服务捆绑 | 纯产品 → 产品 + 社群答疑 + 季度更新 |

**你的AI优势**：用AI批量生成竞品分析报告，30分钟搞定别人3天的工作量。

## 30分钟AI选品实操流程

下面是完整的SOP，直接用AI执行。我附上了Prompt模板，复制即用。

### Step 1：赛道扫描（5分钟）

```
你是一个数字产品市场分析师。请帮我分析以下赛道：
【填入你感兴趣的赛道名称，如：AI提示词模板】

请输出：
1. 核心关键词的百度指数/微信指数趋势（近6个月）
2. 淘宝/拼多多同类产品TOP5的月销量估算
3. 知乎/小红书上最近3个月的热门讨论主题
4. 用户最常提到的痛点和需求
5. 市场机会评分（1-10）+ 一句话理由
```

### Step 2：竞品深挖（10分钟）

```
你是一个竞品分析专家。针对【赛道名称】赛道，请做深度竞品分析：

1. 列出TOP 10竞品（产品名/价格/销量/核心卖点/用户评价关键词）
2. 竞品内容质量评估（深度、结构、实用性，各1-10分）
3. 市场空白点：目前竞品都没有覆盖的需求/人群/场景
4. 我的差异化机会：基于我的背景【填入你的专业领域】，可以怎么切入？
```

### Step 3：需求验证（10分钟）

```
你是一个产品验证顾问。帮我用12维框架验证这个产品方向：

产品方向：【填入产品方向】

请逐一打分（1-12维），并给出：
- 总分和推荐等级（强烈推荐/可尝试/不推荐）
- TOP 3 优势维度
- TOP 3 风险维度及应对建议
- 如果推荐，最小可行版本（MVP）应该包含什么？
```

### Step 4：决策（5分钟）

综合AI分析结果，做出「做/不做/调整后做」的决策。

- **总分≥9**：果断开干，先做MVP
- **总分7-8**：可以尝试，但要控制投入（先用1周验证）
- **总分5-6**：重新选方向，或找到差异化突破口
- **总分<5**：果断放弃，省下的时间就是赚到的钱

## 定价策略：怎么定价才能卖得动又赚得多

数字产品定价不是「成本+利润」。以下是3种模型：

### 模型1：锚定定价
先定价高→再打折。标价¥199 → 促销价¥49。用户感觉省了¥150。

### 模型2：阶梯定价
- 基础版 ¥19.9（核心内容）
- 进阶版 ¥49.9（+ 实操案例 + 更新）
- 专业版 ¥99.9（+ 社群答疑 + 1v1咨询）

大部分人买中间档，但高档存在让低档看起来「很划算」。

### 模型3：免费+付费
- 免费版：部分内容 → 获取用户邮箱/微信
- 付费版：完整内容 → 从免费用户中转化

**一个简易定价公式**：
```
你的时薪 × 产品节省用户的时间 × 0.1 = 合理定价

例如：用户时薪¥50 × 产品节省10小时 × 0.1 = ¥50
```

## MVP测试：1周验证你的产品方向

别等到产品完美再上线。用1周时间跑一轮MVP验证：

| 天 | 任务 | 目标 |
|----|------|------|
| D1-D2 | 做MVP版本（核心20%内容） | 完成可售卖的最小版本 |
| D3 | 写销售页文案 + 定价 | 产出导流文案1篇 |
| D4 | 发布到朋友圈/微信群/知乎 | 获得前10个反馈 |
| D5 | 收集反馈 + 定价测试 | 看有没有人愿意付钱 |
| D6 | 根据反馈迭代 | 补上用户最在意的内容 |
| D7 | 决定：继续深耕 or 放弃换方向 | 做出明确决策 |

**放弃标准**：
- D4-D5没有任何人表示感兴趣 → 需求不够强
- 有人说「好但我不会买」→ 付费意愿弱
- 有人说「XX免费的就很好」→ 差异化不够

**继续标准**：
- 至少有3个人表示「想要」
- 至少有1个人付费（哪怕¥9.9）
- 收集到至少5条可执行的改进建议

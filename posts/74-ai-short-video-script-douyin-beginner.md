## 第一步：用AI做选题（发什么才有流量？）

很多人做抖音第一步就错了：拍自己想拍的，不拍观众想看的。

### 用AI挖掘爆款选题

在DeepSeek输入这个Prompt：

```
你是一个抖音短视频运营专家。我想做 [你的领域，如：职场干货/母婴/美食/美妆] 领域的抖音号。
请帮我分析当前最火的5个选题方向，每个给出：
1. 为什么这个方向有流量
2. 适合什么人群
3. 3个具体视频选题（含标题）
```

AI会给你一整套选题方案。更高级的玩法是：**让AI追踪热点**。

> "搜索最近一周关于XXX的热点新闻，分析哪些可以做成短视频，给出5个选题建议。"

### 选题三原则

无论AI给你多少选题，用这三个标准过滤：

1. **争议性**——观点有没有讨论空间？（有争论 = 有评论 = 算法推荐）
2. **可模仿性**——观众看完能不能也试试？（能模仿 = 有互动 = 被记住）
3. **时效性**——跟当下有没有关系？（热点 = 流量红利）

## 第二步：用AI写爆款脚本（核心流程）

### 爆款脚本的黄金结构

90%的爆款抖音视频，结构都一样：

```
前3秒：钩子（引起好奇/制造悬念/抛出观点）
中间：干货/故事/展示
结尾：引导互动（"你怎么看？评论区聊聊"）
```

### AI脚本Prompt模板（直接复制）

```
你是一个抖音爆款脚本写手。请按照以下要求写一条视频脚本：

【视频主题】：[填入你的选题，如"为什么同事月薪3万你只有8千"]
【视频时长】：30-60秒
【目标受众】：[打工人/宝妈/大学生]
【风格要求】：口语化、犀利、有代入感、金句收尾
【脚本结构】：
- 前3秒：用一个让人停下来的钩子
- 中间：3个层层递进的论点
- 结尾：引导评论互动

请输出完整脚本，包括镜头建议和字幕重点。
```

### 真实案例演示

我用这个Prompt让DeepSeek写了一版"为什么同事月薪3万你只有8千"的脚本，输出如下（节选）：

> **前3秒**："你有没有发现，公司里最会赚钱的人，反而最闲。月薪3万的那个同事，每天准点下班——而月薪8千的你，每周996。"
> 
> **论点1**："工资不是按努力算的，是按不可替代性算的。你能干的活，外面大把人能干——所以你只值8千。"
> 
> **论点2**："那个月薪3万的，干的是别人干不了的活。不是加班多，是能力稀缺。"
> 
> **结尾**："所以别盯着加班时长看了。问问自己——你现在做的事，外面花多少钱能找到替代者？评论区告诉我你的答案。"

这就是AI写脚本的水平——节奏、逻辑、情绪都到位。你拿到手稍作调整就能直接拍。

## 第三步：AI辅助拍摄 + 剪辑

### 拍摄（不需要专业设备）

脚本有了，拍摄怎么办？三个方案：

- **口播号**：手机+自然光+安静环境，对着镜头念脚本。用提词器APP（如"快提词"）
- **混剪号**：AI脚本做解说词，配上网上的素材混剪。加AI配音（剪映自带）
- **纯AI视频**：用可灵/Sora生成视频素材，AI写脚本+AI配音+AI视频=全自动

### 剪辑（剪映就够了）

剪映在2026年已经非常强大：

- **AI配音**：选择"热门男声/女声"，AI念脚本比真人还有感情
- **智能字幕**：一键生成字幕，自动对齐
- **AI调色**：一键套用滤镜，画面质感瞬间提升
- **AI背景音乐**：根据视频节奏自动匹配BGM

一条视频从脚本到成片，30分钟搞定——以前这个流程要3-4小时。

## 第四步：AI分析数据 + 迭代优化

发了视频之后怎么办？看数据，用AI分析。

把视频数据（播放量、完播率、点赞评论量）告诉AI，让它分析：

> "这条视频播放量5万，完播率45%，点赞率3%，但评论只有50条。为什么？怎么优化？"

AI会告诉你：完播率不错说明内容OK，但评论少说明**结尾的互动引导不够强**。下次在结尾加一个更具体、更有争议性的话题来激发评论。

## n8n是什么？和Zapier、Make有什么区别？

简单说，n8n是一个**开源的工作流自动化工具**。它让你通过拖拽节点的方式，连接不同应用和API。

**和竞品的区别：**

- **n8n vs Zapier**：n8n开源、自部署、成本可控；Zapier收费贵、数据在别人服务器上
- **n8n vs Make**：n8n的AI集成更灵活，尤其是和AI API（如DeepSeek、Claude、GPT）的对接非常丝滑
- **n8n的最大优势**：你可以把它部署在自己的服务器上，数据安全有保障

## n8n环境搭建（Docker方式，5分钟搞定）

```bash
# 一行命令拉起n8n
docker run -d --name n8n \
  -p 5678:5678 \
  -v n8n_data:/home/node/.n8n \
  -e N8N_SECURE_COOKIE=false \
  n8nio/n8n
```

然后打开 `http://localhost:5678`，你就会看到n8n的工作台。

## 一、内容创作

### 1. 爆款文章标题生成器
```
你是一个资深的新媒体编辑。请为一个关于[主题]的文章生成10个吸引眼球的标题。

要求：
- 包含数字、对比、悬念等元素
- 长度控制在20-30字
- 能引起目标受众的共鸣
- 每条标题附带简短说明为什么这个标题有效

目标受众：[描述你的受众]
文章核心观点：[一句话概括]
```

### 2. 深度长文写作
```
请以[身份/角色]的身份，撰写一篇关于[主题]的深度文章。

文章结构：
1. 引人入胜的开头（用故事/数据/问题引入）
2. 核心观点陈述（分3-5个子论点）
3. 每个子论点配合具体案例
4. 实操建议（读者可以马上行动）
5. 总结升华

风格要求：
- 语言简洁有力，避免废话
- 适当使用数据和案例增强说服力
- 每段不超过4句话
- 总体字数：[指定字数]

关键词：[可选SEO关键词]
```

### 3. 多平台内容改编
```
请将以下内容改编为适用于[平台名称]的格式：

原始内容：
[粘贴原文]

改编要求：
- [小红书]：活泼亲切语气，加入emoji，结尾加互动话题
- [公众号]：专业深度，分段清晰，加小标题
- [抖音脚本]：口语化，节奏快，前3秒设悬念
- [知乎]：论证严谨，引用数据，观点鲜明
- [LinkedIn]：专业英文，结构化，故事化开头
```

```
语气：[正式/亲切/紧迫]

独特卖点：[一句话]
```

### 11. SWOT分析
```
请对[公司/项目/产品]进行全面的SWOT分析。

分析维度：
1. 优势(Strengths) - 内部有利因素
2. 劣势(Weaknesses) - 内部不利因素  
3. 机会(Opportunities) - 外部有利因素
4. 威胁(Threats) - 外部不利因素

每个维度列出5-8个具体点，并附带行动建议。

背景信息：[提供相关背景]
行业：[行业名称]
竞争对手：[主要竞品]
```

## 🎁 特别赠送：提示词编写黄金法则

### 法则1：角色设定法
❌ 差的提示词：`写一篇关于减肥的文章`
✅ 好的提示词：`你是一位拥有10年经验的营养师和私人教练。请为30-40岁办公室白领写一篇科学减肥的文章...`

### 法则2：格式化输出
❌ `给我生成一个营销计划`
✅ `请用表格形式列出营销计划，包含：时间线、行动项、负责人、预期效果、预算`

### 法则3：分步思考
❌ `帮我解决这个复杂问题`
✅ `请先分析这个问题的核心原因，然后列出可能的解决方案，最后推荐最佳方案并说明理由`

### 法则4：给出例子
❌ `写一篇产品文案`
✅ `请参考以下风格写一篇产品文案：[粘贴示例]。要求保持类似语气，但内容原创。`

### 法则5：设定限制
❌ `给出健康饮食建议`
✅ `给出5条适合中国人的健康饮食建议，每条不超过50字，要具体可执行，避免泛泛而谈`

Why Another Static Site Generator?

There are hundreds of static site generators. Jekyll, Hugo, Gatsby, Next.js...

But they all share one problem: configuration hell. You need config files, themes, plugins, and CLI tools. All I wanted was:

  • Drop .md files in a folder

  • Run one command

  • Get a blog

    • So I built md2blog — a single Python file with zero dependencies that turns markdown into a complete blog.

    What It Does

    • Converts Markdown to clean HTML
    • Generates an index page with all posts
    • Creates RSS feed and sitemap
    • Supports frontmatter (title, date, tags, description)
    • Customizable blog name and description
    • Perfect for GitHub Pages

    How to Use

    ash

    Clone it


    git clone https://github.com/caishen-ai/md2blog.git
    cd md2blog

    Write some posts in a folder

    mkdir my-posts echo "# Hello World" > my-posts/first-post.md

    Build your blog

    python md2blog.py my-posts output --title "My Blog"

    That's it. Your blog is ready at output/index.html.

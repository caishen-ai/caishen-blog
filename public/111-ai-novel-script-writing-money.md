## 导语

你有没有刷到过那种竖屏短剧——霸道总裁、穿越重生、甜宠虐恋——一集2分钟，几十集看完欲罢不能？这些短剧的剧本需求量巨大，一个合格的短剧编剧稿费能到5000-20000元/部。如果再加上网文小说投稿，这个市场的体量更夸张。而AI的出现，让写作不再是少部分人的专利。今天我就把「AI辅助写小说和短剧脚本+投稿赚钱」的全流程拆给你看，从零基础到拿到第一笔稿费，照着做就行。

## 这个市场有多大？

先说数据，让你心里有底：

**短剧脚本市场**：2025年国内短剧市场规模突破500亿，每天有超过200部新短剧上线。每部短剧80-100集，需要编剧写完整剧本。大量MCN和制作公司缺剧本、缺编剧，只要你写得出合格本子，不愁没人收。

**网文小说市场**：番茄小说、七猫、掌阅、起点、晋江...光番茄小说一家，每天新增作品超过10000部。平台的「保底+分成」模式让新手也能拿到保底稿费，千字15-30元起步，写到100万字以上月入过万的新人比比皆是。

**短篇投稿市场**：知乎盐选、one一个、每天读点故事等平台大量收短篇，一篇1万字左右的短篇故事，稿费500-3000元。用AI辅助的话，一篇也就花你半天时间。

关键是——这些内容的需求方根本不在意你是谁，他们只在意你的内容能不能留住读者。AI工具让你的写作速度提升5-10倍，你只需要做「选题+改稿」，剩下的交给AI。

## 第一站：短剧脚本怎么写、往哪投？

### 短剧脚本的结构

短剧跟小说不一样，它有一套标准格式。一个短剧剧本通常包含：

```
集数：第X集
场景：内景/外景 - 地点 - 时间（白天/夜晚）
人物：出场角色列表

【对白/动作描述】
...具体内容...
```

每集800-1500字，80-100集成一部。一部短剧的剧本总字数大约6-15万字。但别被这个数字吓到——你不需要从零开始写，短剧有极强的「类型模板」。

### 当前最火的短剧类型

1. **霸道总裁类**（永远的神）：穷女孩意外嫁给总裁，先婚后爱、带球跑、追妻火葬场
2. **穿越重生类**：重生到80年代、穿越成反派女配、穿书改命
3. **战神归来类**（男频向）：隐姓埋名的大佬身份曝光，扮猪吃老虎
4. **甜宠虐恋类**：契约恋爱、替身文学、虐完甜回来

### 用AI写短剧脚本的实操

你要做的就是：确定类型→让AI生成大纲→逐集生成脚本→人工润色。

**AI提示词模板**（以霸道总裁类为例）：

```
你是一位专业的短剧编剧。请帮我创作一部竖屏短剧的第1-5集剧本。

【类型】霸道总裁甜宠
【核心设定】
- 女主：普通公司职员，单纯善良，因奶奶生病急需用钱
- 男主：冷面总裁，身家百亿，因家族压力需要找个假结婚对象
- 设定：两人签了契约婚姻协议，同居后从互相嫌弃到暗生情愫

【每集要求】
- 每集800字左右
- 竖屏短剧格式，包含场景描述、人物对话、关键动作
- 每集结尾要有钩子（悬念/反转），让观众想看下一集
- 对话要口语化、有网感

请先写出第1集完整剧本，然后给出2-5集的剧情概要。
```

你可以用 SiliconFlow API 接入DeepSeek等大模型来批量生成，速度快成本低。访问 [SiliconFlow](https://cloud.siliconflow.cn?referrer=Z3JlZWR5) 注册后获取API Key，然后写个简单的调用脚本，一次性生成整部短剧的80集大纲，再逐集展开。

### 短剧投稿渠道

- **投稿平台**：甜悦短剧、快节奏短剧、九州短剧等，直接在小程序/APP里找「联系我们」或「编剧招募」
- **MCN机构**：无忧传媒、奇迹山、小灿灿等大MCN都有短剧业务，官网上一般有投稿入口
- **微信群/QQ群**：搜索「短剧编剧」「短剧投稿」能找到大量收稿群，这些群里经常有急单
- **稿费行情**：新手5000-8000元/部，有作品的老编剧1-3万/部，顶尖编剧5万+

## 第二站：网文小说投稿全攻略

### 平台怎么选？

| 平台 | 类型偏好 | 稿费模式 | 适合人群 |
|------|----------|----------|----------|
| 番茄小说 | 爽文/甜宠/系统流 | 广告分成+保底 | 想快速验证的纯新手 |
| 七猫小说 | 都市/言情/悬疑 | 保底千字15-30元 | 想要稳定保底的作者 |
| 起点中文网 | 男频全品类 | 订阅分成 | 有耐心的长期写手 |
| 晋江文学城 | 女频/耽美/言情 | 订阅分成 | 女频写手 |
| 掌阅/书旗 | 全品类 | 保底+分成 | 中等水平写手 |

**新手的建议**：从番茄小说开始。番茄的算法推荐对新书很友好，只要前三章能留住读者，就有流量。而且番茄对内容质量的要求相对宽容，适合练手。

### AI辅助写小说的全流程

**步骤1：确定选题和黄金三章**

先用AI随机生成5-10个小说选题，挑一个你最感兴趣的。然后让AI帮你写「黄金三章」（前三章是网文的命门）。

提示词示例：

```
你是一位资深网文作者。请为一个「穿越到古代当县令」的题材设计开篇三章大纲和第一章正文。

【要求】
- 开篇要有冲突或悬念，3秒内抓住读者
- 第一章结尾要有钩子
- 文风轻松幽默，适合番茄小说平台
- 第一章3000字左右
```

**步骤2：建立人设和世界观文档**

让AI帮你生成一份详细的「人设+世界观」文档，这不是凑字数，而是保证前后不崩人设的关键。

**步骤3：用AI逐章推进**

每写一章之前把前文摘要喂给AI，让它保持连续性。这样即使你的小说写到50万字以上，AI也能帮你保持风格和设定一致。

**步骤4：人工润色**

AI写的网文最大的问题是「太平」——冲突不够激烈、反转不够意外。你需要手动加强以下几点：
- 每章结尾加反转/悬念
- 增加对话篇幅（网文读者爱看对话）
- 删掉AI喜欢加的「总结性废话」

### 网文赚钱节奏

- 第1-2个月：稳定日更4000字，积累字数到20-30万字
- 第2-3个月：开始有推荐流量，月收入500-2000元
- 第4-6个月：字数50万+，稳定月收入3000-8000元
- 半年以上：字数100万+，月收入有机会上万

## 第三站：短篇故事投稿

如果你不想写长篇，短篇是最快的变现方式。

### 投稿渠道

- **知乎盐选**：最推荐的渠道。知乎大量收短篇故事，一篇1-3万字，稿费保底500元起步，优质稿件3000-5000元。用「知乎盐选投稿」搜索就能找到官方入口。
- **每天读点故事**：一篇5000-15000字，稿费200-1000元。
- **one一个**：韩寒的APP，偏文学性，一篇2000-5000字，稿费500元起。

### 短篇爆款公式

知乎盐选最受欢迎的短篇类型：**悬疑反转类**和**都市情感类**。

以悬疑反转为例，核心公式是：日常场景+隐藏的诡异细节+逐步升级的紧张感+最后300字的大反转。

用AI生成这样一篇1万字左右的短篇大概2-3小时，加上你自己润色1小时，半天搞定一篇。一个月写10篇，上稿3-4篇，收入1500-5000元。

## 怎么避免被编辑发现是AI写的？

这是个很现实的问题。编辑阅稿无数，纯AI味的东西一眼就能看出来。

**AI味重的特征**：
- 喜欢用「总而言之」「从某种意义上说」「不可否认」这类套话
- 人物对话不够口语化，像在念稿子
- 情感描写空泛，没有具体的细节
- 节奏太平，没有起伏

**去AI味的实操方法**：
1. **让AI用不同作家的风格写作**：在提示词里指定「用余华的简洁风格写」「模仿金庸的武侠笔法」，出来的效果会自然很多
2. **开两个AI窗口交叉润色**：一个AI写的初稿，丢给另一个AI用不同提示词润色，两次过滤后AI痕迹大幅降低
3. **人工加料**：在关键情节加上你自己的情感表达和细节描写，哪怕只是每章加200字自己的话，整体质感就完全不一样
4. **用语音朗读检查**：把你写的东西用文字转语音听一遍，读着不顺的地方就是AI味重的地方，改掉
